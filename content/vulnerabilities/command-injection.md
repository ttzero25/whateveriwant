# 명령 주입: 셸과 인자의 경계

> **TL;DR**
>
> 외부 데이터를 명령문으로 조합하면 운영체제 작업의 의미가 바뀔 수 있습니다. 셸 호출을 줄이고 실행 파일과 인자를 분리해야 합니다.

AI 작성 해설

## 발생 원리와 영향

프로그램이 외부 입력을 셸 문법으로 해석하거나 의도하지 않은 옵션으로 전달할 때 문제가 생깁니다. 영향 범위는 실행 계정의 파일·프로세스 권한에 따라 달라집니다.

## 가상 사례로 이해하기

가상 이미지 변환 서비스는 문자열 명령을 만들기보다 라이브러리 API를 사용할 수 있습니다. 외부 프로그램이 필요하면 실행 파일은 고정하고 허용된 작업 인자만 전달합니다.

## 예방과 수정

- 가능하면 셸 대신 목적에 맞는 라이브러리 API를 사용합니다.
- 외부 실행이 필요하면 실행 파일과 인자 배열을 분리하고 인자의 의미도 검증합니다.
- 변환 작업의 파일 접근·실행 시간·자원과 서비스 계정 권한을 제한합니다.

## 수정 후 확인할 조건

정상 파일 이름에 공백이 있어도 하나의 인자로 처리되는지 확인합니다. 사용자가 지정할 수 있는 옵션과 실제 호출 API의 셸 사용 여부를 코드 리뷰합니다.

## 자주 하는 오해

셸을 사용하지 않아도 인자가 프로그램의 옵션으로 해석될 수 있습니다. 인자 분리와 의미 검증은 함께 필요합니다.

## 확인 질문

문자열 이스케이프 하나로 셸 문법과 실행 프로그램의 모든 옵션 규칙을 해결할 수 있을까요?
