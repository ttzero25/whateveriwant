## 원칙과 접근 제어

| 용어 | 영어 | 의미 |
|---|---|---|
| 기밀성·무결성·가용성 | CIA triad | 읽기·변경·이용 가능성의 보호 목표 |
| 위협 모델링 | Threat modeling | 자산과 경계를 바탕으로 위협·대응을 분석 |
| 공격 표면 | Attack surface | 시스템과 상호작용할 수 있는 진입·이탈 지점 |
| 최소 권한 | Least privilege | 업무에 필요한 최소 범위의 권한 부여 |
| 심층 방어 | Defense in depth | 서로 보완하는 여러 통제로 실패 영향 제한 |
| 인증 | Authentication | 주장한 신원 검증 |
| 인가 | Authorization | 자원과 작업의 허용 여부 결정 |
| 다중 요소 인증 | MFA | 서로 다른 종류의 인증 요소 결합 |
| 역할 기반 접근 제어 | RBAC | 역할을 기준으로 권한 결정 |
| 속성 기반 접근 제어 | ABAC | 주체·자원·환경 속성으로 판단 |
| 관계 기반 접근 제어 | ReBAC | 소유·공유 등의 관계로 판단 |
| 세션 | Session | 여러 요청에 걸쳐 유지하는 상호작용 상태 |
| 권한 위임 | OAuth 2.0 | 클라이언트에 자원 접근 권한을 위임하는 틀 |
| OpenID Connect | OIDC | OAuth 2.0 위에 구축한 인증 계층 |

관련 해설과 출처: [보안 원칙](principles.md) · [인증과 인가](authentication-authorization.md)

## 암호학

| 용어 | 영어 | 의미 |
|---|---|---|
| 암호화 | Encryption | 키로 평문을 암호문으로 변환 |
| 해시 | Cryptographic hash | 입력에서 고정 길이 요약값 생성 |
| 메시지 인증 코드 | MAC / HMAC | 공유 비밀키로 메시지 무결성 검증 |
| 전자서명 | Digital signature | 개인키로 서명하고 공개키로 검증 |
| 인증된 암호화 | AEAD | 암호화와 무결성 검증, 부가 데이터 인증 |
| 논스 | Nonce | 프로토콜의 요구에 따라 중복 등을 관리하는 값 |
| 솔트 | Salt | 비밀번호별 해시 입력을 다르게 만드는 값 |
| 키 유도 함수 | KDF | 키 재료 등에서 목적에 맞는 키를 유도하는 함수 |

관련 해설과 출처: [암호학](cryptography.md)

## 웹·시스템·네트워크

| 용어 | 영어 | 의미 |
|---|---|---|
| 인젝션 | Injection | 데이터가 명령이나 질의 구문으로 해석되는 문제 |
| 크로스 사이트 스크립팅 | XSS | 신뢰할 수 없는 내용이 웹에서 실행되는 문제 |
| 사이트 간 요청 위조 | CSRF | 인증 정보가 자동 첨부된 원치 않는 요청 문제 |
| 서버 측 요청 위조 | SSRF | 서버 요청 목적지가 외부 입력에 의해 좌우되는 문제 |
| 동일 출처 정책 | SOP | 브라우저가 출처 사이의 접근을 제한하는 정책 |
| 교차 출처 리소스 공유 | CORS | 다른 출처에 응답 읽기 등을 허용하는 브라우저 정책 |
| 콘텐츠 보안 정책 | CSP | 페이지의 리소스 로드와 실행 등을 제한하는 정책 |
| 해제 후 사용 | Use-after-free | 수명이 끝난 메모리 객체에 접근 |
| 주소 공간 배치 난수화 | ASLR | 메모리 배치의 예측을 어렵게 하는 완화 기법 |
| 실행 방지 | NX / DEP | 실행 불가 영역의 명령 실행 제한 |
| 제어 흐름 무결성 | CFI | 프로그램의 허용 제어 흐름을 제한 |
| 전송 계층 보안 | TLS | 통신 채널의 암호화·무결성·상대 인증 |
| 상호 TLS | mTLS | 클라이언트와 서버가 서로 인증서를 검증 |
| 네트워크 분리 | Network segmentation | 네트워크를 나누고 구간 간 연결을 통제 |
| 침입 탐지·방지 시스템 | IDS / IPS | 의심 활동을 탐지하거나 차단 |

관련 해설과 출처: [웹 보안](web-security.md) · [시스템 보안](system-security.md) · [네트워크 보안](network-security.md) · [목차](index.md)
