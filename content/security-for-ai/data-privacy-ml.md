# 학습 데이터 프라이버시

> **TL;DR**
>
> 모델은 학습 데이터를 어느 정도 기억하므로, 멤버십 추론(그 샘플이 학습에 쓰였는가)이나 데이터 추출(학습 문장 복원)로 프라이버시가 새어 나갈 수 있습니다. 차등 프라이버시와 최소 수집으로 완화합니다.

AI 작성 해설

## 모델은 데이터를 기억한다

특히 과적합됐거나 반복 노출된 샘플을 모델이 기억하면, 출력·확신도에서 그 흔적이 드러납니다. 이는 학습에 개인정보·기밀이 섞였을 때 곧 유출 경로가 됩니다. 데이터 설계 관점은 [보안 데이터·라벨·누수](../ai-for-security/security-data.md), 프라이버시 원칙은 [데이터 프라이버시](../security/data-privacy.md)와 이어집니다.

| 공격 | 노리는 것 |
|---|---|
| 멤버십 추론 | 특정 샘플이 학습에 포함됐는지 판정 |
| 속성 추론 | 학습 집단의 민감 속성 추정 |
| 데이터 추출 | 학습에 쓰인 실제 문장·이미지 복원(LLM 암기) |
| 모델 반전 | 출력으로부터 입력 특징 재구성 |

## 멤버십 추론의 직관

모델은 학습에 쓴 샘플에 더 높은 확신을 보이는 경향이 있습니다. 공격자는 이 확신도 차이를 이용해 "이 샘플은 학습에 쓰였다"를 판정합니다. 과적합이 심할수록 쉬워집니다([정규화](../ai/regularization.md)로 완화).

```python
# 개념: 손실/확신도 임계로 멤버십을 추정(방어 평가에 쓰는 절차)
def membership_guess(model, sample, threshold):
    confidence = model.predict_proba(sample).max()
    return confidence > threshold      # 학습 샘플일수록 확신이 높은 경향
# 방어 지표: 학습/비학습 샘플의 확신도 분포가 겹칠수록(구분 불가) 안전
```

## 방어

- **차등 프라이버시(DP)**: 학습에 잡음을 더해 한 샘플의 기여를 제한합니다(DP-SGD). 개별 데이터의 존재 여부가 결과를 거의 바꾸지 않게 만듭니다.
- **최소 수집·정제**: 애초에 민감 데이터를 넣지 않고, 중복·암기 위험이 큰 데이터를 줄입니다([데이터 프라이버시](../security/data-privacy.md)).
- **과적합 완화**: 정규화·조기 종료로 암기를 줄입니다.
- **출력 통제**: 확률 전체 대신 최소한만 반환해 추론 단서를 줄입니다([모델 추출](model-extraction.md)과 함께).
- **연합 학습**: 원자료를 모으지 않고 갱신만 공유(단, 갱신에서의 누출은 별도 방어 필요).

## 자주 하는 오해

익명화했다고 안전한 것이 아닙니다. 모델이 패턴을 기억하면 재식별·추출이 가능하므로, 프라이버시는 데이터 처리와 학습·출력 전 구간에서 다뤄야 합니다.
