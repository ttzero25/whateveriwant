# 모델 추출과 도용

> **TL;DR**
>
> 공격자가 API에 질의를 반복해 모델의 동작을 모사한 복제본을 만들 수 있습니다(모델 추출). 지식재산·경쟁우위를 잃고, 복제본으로 회피 공격을 준비할 수도 있습니다. 질의 제한과 응답 최소화로 완화합니다.

AI 작성 해설

## 질의만으로 모델을 훔친다

모델 가중치에 직접 접근하지 못해도, 입력을 넣고 출력을 관찰하는 것을 대량 반복하면 그 입력-출력 관계를 학습한 **대리 모델**을 만들 수 있습니다. 특히 확률·점수 같은 풍부한 출력을 주면 추출이 쉬워집니다. AI 시스템 보안 전반은 [AI 시스템 보안](securing-ai-systems.md)에서 다룹니다.

## 왜 위험한가

- **지식재산 유출**: 비용을 들여 만든 모델을 저비용으로 복제.
- **회피 준비**: 복제본으로 오프라인에서 [적대적 예제](adversarial-ml.md)를 만들어 원본 공격.
- **멤버십·데이터 추론**과 결합해 [학습 데이터 프라이버시](data-privacy-ml.md)까지 위협.

```python
# 개념: 대리 모델 학습을 위한 질의 수집(공격자 관점) — 방어 설계 이해용
def steal(query_api, inputs):
    data = []
    for x in inputs:
        y = query_api(x)          # 확률/점수를 그대로 주면 추출이 쉬워진다
        data.append((x, y))
    surrogate = train_model(data) # 입력-출력 관계를 모사한 복제본
    return surrogate
# 방어: 응답을 최상위 라벨만, 정밀도 낮춰 반환하고 질의를 제한한다
```

## 방어

- **응답 최소화**: 전체 확률 벡터 대신 최상위 라벨만, 정밀도를 낮춰 반환합니다.
- **질의 제한·이상 탐지**: 계정·키별 [레이트 리밋](../security/availability-dos.md)과, 결정 경계를 훑는 비정상 질의 패턴 탐지.
- **워터마킹**: 모델 출력에 식별 가능한 표식을 심어 복제본을 사후 입증.
- **인증·과금**: 익명 대량 질의를 막고, 접근을 인증된 사용자로 제한([API 보안](../security/api-security.md)).

## 자주 하는 오해

모델 가중치를 공개하지 않았다고 안전한 것이 아닙니다. 충분한 질의 예산만 있으면 동작을 모사할 수 있으므로, "블랙박스라 안전"은 성립하지 않습니다.

## 확인 질문
