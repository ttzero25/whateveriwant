## 자료구조

| 용어 | 영어 | 의미 |
|---|---|---|
| 배열 | Array | 연속 메모리의 인덱스 접근 |
| 연결 리스트 | Linked list | 노드가 다음을 가리키는 구조 |
| 스택·큐 | Stack / Queue | LIFO / FIFO 순서 |
| 해시 테이블 | Hash table | 키를 인덱스로 매핑, 평균 O(1) |
| 충돌 | Collision | 다른 키가 같은 버킷으로 |
| 부하율 | Load factor | 원소 수 / 버킷 수 |
| 이진 탐색 트리 | BST | 왼쪽<노드<오른쪽 불변식 |
| 자가 균형 트리 | AVL / Red-Black | 회전으로 O(log n) 유지 |
| 힙 | Heap | 부모가 자식보다 우선 |
| 우선순위 큐 | Priority queue | 최우선 원소를 먼저 |

## 복잡도와 알고리즘

| 용어 | 영어 | 의미 |
|---|---|---|
| 시간 복잡도 | Big-O | 입력 증가에 따른 비용 증가율 |
| 분할 상환 | Amortized | 여러 연산에 걸친 평균 비용 |
| 안정 정렬 | Stable sort | 같은 값의 상대 순서 보존 |
| 이진 탐색 | Binary search | 정렬 데이터에서 O(log n) |
| BFS·DFS | Breadth/Depth-first | 너비·깊이 우선 그래프 탐색 |
| 위상 정렬 | Topological sort | DAG의 의존 순서 |

## 설계 기법

| 용어 | 영어 | 의미 |
|---|---|---|
| 분할 정복 | Divide and conquer | 독립 하위 문제로 쪼갬 |
| 동적 계획법 | Dynamic programming | 겹치는 부분 문제 재사용 |
| 메모이제이션 | Memoization | 결과 캐시로 재계산 방지 |
| 그리디 | Greedy | 매 단계 지역 최적 선택 |
| 백트래킹 | Backtracking | 제약 위반 시 되돌아가 탐색 |
| 가지치기 | Pruning | 불가능한 탐색 경로를 조기 차단 |
