## 목적별 읽기

- 처음 시작: 개요 → 대칭 → 비대칭 → 해시 → 서명
- 프로토콜 이해: 키 교환 → PKI → [TLS·HTTP/2·QUIC](../network/tls-quic.md)
- 저장·인증 구현: 비밀번호 저장 → 난수 → 키 관리
- 보안 전반과 연결: [Security 학습 가이드](../security/index.md)

## 한 가지 원칙

같은 알고리즘도 모드·nonce·키 관리에서 무너집니다. 자체 암호 설계를 피하고 검증된 라이브러리의 인증 암호화(AEAD)와 표준 키 관리를 사용하세요. 이 섹션은 보안(Security)에서 분리해 별도로 정리한 암호학 전용 컬렉션입니다.

## 출처와 문서 성격

NIST·IETF RFC·OWASP 공식 자료를 참고한 한국어 해설입니다. 각 문서에 출처를 연결했으며 원문 번역이나 전문 복제가 아닙니다. 예시 코드는 개념 설명용이며, 실제 구현은 검증된 암호 라이브러리를 사용하세요.
