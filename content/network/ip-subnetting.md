# IPv4·IPv6와 서브넷: 주소·CIDR·계산

> **TL;DR**
>
> IP 주소와 프리픽스는 어떤 네트워크 범위에 속하는지 표현합니다. CIDR의 /n은 네트워크 부분의 비트 수이며, 주소 개수와 실제 사용 가능한 호스트 수는 구분해야 합니다.

AI 작성 해설

## 주소와 프리픽스

IPv4 주소는 32비트, IPv6 주소는 128비트입니다. IPv4의 /24는 앞 24비트가 프리픽스라는 뜻이며 나머지 8비트로 256개 주소를 표현합니다. 고정된 클래스 A·B·C보다 실제 프리픽스 길이로 범위를 판단합니다. [RFC 4632: CIDR](https://www.rfc-editor.org/rfc/rfc4632)

## IPv4 계산 예시

설명용 주소 192.0.2.130/26을 생각해 봅시다. /26의 마스크는 255.255.255.192이고 주소 묶음의 크기는 64입니다.

| 항목 | 값 |
|---|---|
| 네트워크 주소 | 192.0.2.128 |
| 전체 범위 | 192.0.2.128–192.0.2.191 |
| 일반적인 브로드캐스트 서브넷의 호스트 범위 | 192.0.2.129–192.0.2.190 |
| 전체 주소 / 위 조건의 호스트 주소 | 64 / 62 |

2^(32−n)−2는 일반적인 IPv4 브로드캐스트 서브넷의 설명에 유용하지만 /31 점대점 링크나 /32 호스트 경로까지 무조건 적용하는 공식은 아닙니다. 경로의 표현과 링크의 주소 할당 정책을 함께 봅니다. [RFC 3021](https://www.rfc-editor.org/rfc/rfc3021)

## IPv6의 차이

IPv6는 16진수와 콜론으로 주소를 표현하고 연속된 0 구간을 한 번 ::로 줄일 수 있습니다. 링크 로컬 주소는 같은 링크 범위에서 의미가 있으므로 어느 인터페이스인지가 중요할 수 있습니다. IPv6에는 IPv4 방식의 브로드캐스트가 없으며 멀티캐스트 등으로 필요한 전달을 수행합니다. [RFC 8200](https://www.rfc-editor.org/rfc/rfc8200)

## 주소의 범위와 용도

사설 주소, 루프백, 링크 로컬, 문서 예제용 주소는 서로 다른 목적의 범위입니다. 사설 주소라고 안전하거나 전역 주소라고 인터넷에서 반드시 도달 가능한 것은 아닙니다. 라우팅·방화벽·서비스 상태가 도달성을 결정합니다. 이 글의 192.0.2.0/24와 2001:db8::/32는 문서 예시를 위한 주소 범위입니다. [RFC 5737](https://www.rfc-editor.org/rfc/rfc5737), [RFC 3849](https://www.rfc-editor.org/rfc/rfc3849)

## 확인 질문

192.0.2.130/26과 192.0.2.200/26은 같은 서브넷일까요? 마지막 숫자만 비교하지 말고 프리픽스로 범위를 계산해 보세요.
