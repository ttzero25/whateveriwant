# BGP와 자율 시스템 간 라우팅

> **TL;DR**
>
> 인터넷은 자율 시스템(AS)이라는 독립 네트워크들의 집합이며, BGP는 이들 사이에서 "어느 목적지에 어떻게 도달하는가"를 광고·선택하는 경로 벡터 프로토콜입니다. 정책과 신뢰가 핵심이라 잘못된 광고가 전 세계 트래픽을 흔들 수 있습니다.

AI 작성 해설

## AS와 도메인 간 라우팅

한 조직·ISP가 관리하는 네트워크를 자율 시스템(AS)이라 하고 AS 번호로 식별합니다. AS 내부의 경로 선택(OSPF 등)과 달리, AS 사이의 경로는 BGP가 담당합니다. 내부 라우팅·NAT·최장 프리픽스 개념은 [라우팅과 NAT](routing-nat.md)에서 다룹니다.

## 경로 벡터: 전체 경로를 광고한다

BGP는 목적지 프리픽스마다 "이 목적지에 도달하려면 이 AS들을 거친다"는 AS 경로(AS_PATH) 전체를 이웃에게 광고합니다. 수신 측은 여러 광고 중 정책과 경로 길이로 하나를 고릅니다. AS_PATH에 자기 번호가 있으면 버려서 루프를 방지합니다.

```
목적지 203.0.113.0/24 광고 예:
  AS65001 로부터: AS_PATH = [65001, 64500]     ← 2홉
  AS65002 로부터: AS_PATH = [65002, 65003, 64500]  ← 3홉
  → 정책이 같다면 대개 짧은 AS_PATH(65001 경유)를 선택
```

## 정책이 최단 경로보다 우선

BGP 선택은 순수 최단 경로가 아니라 비즈니스 정책이 지배합니다. 고객 경로를 공급자 경로보다 선호하고(비용), LOCAL_PREF·AS_PATH 길이·MED 등을 순서대로 비교합니다. 즉 "가장 짧은 길"이 아니라 "정책상 가장 선호되는 길"이 뽑힙니다.

## 왜 취약한가

BGP는 기본적으로 광고를 **신뢰**합니다. 어떤 AS가 자기 것이 아닌 프리픽스를 광고하면(프리픽스 하이재킹), 그 트래픽이 잘못된 곳으로 흘러 가로채기·차단·감청에 노출됩니다. 과거의 대형 인터넷 장애 다수가 이런 오광고(설정 실수 포함)에서 비롯했습니다.

방어:
- **RPKI**로 "이 프리픽스를 광고할 정당한 AS"를 암호학적으로 검증(ROA)하고, 부적합 경로를 거부합니다.
- 이웃별로 받는·보내는 프리픽스를 필터링합니다(예상 밖 광고 차단).
- 비정상 경로 변화를 모니터링합니다.

이는 신뢰·경로 무결성 문제로 [네트워크 보안](../security/network-security.md), 라우팅 인프라 신뢰의 [제로 트러스트](../security/zero-trust.md) 사고와도 통합니다.
