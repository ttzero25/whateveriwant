# 이산수학과 논리: 명제·집합·관계·불변식

> **TL;DR**
>
> 명제와 집합은 조건을 정확히 표현하고, 관계와 불변식은 구조와 알고리즘의 성질을 설명합니다. 예시가 몇 번 맞는 것과 모든 입력에서 성립함을 보이는 것은 다릅니다.

## 조건을 명제로 표현하기

명제는 참·거짓을 판단할 수 있는 문장입니다. AND·OR·NOT으로 조건을 조합하고, 함의 P → Q는 P가 성립할 때 Q가 성립한다는 뜻입니다. 역 Q → P는 자동으로 따라오지 않습니다. “관리자이면 편집 가능”만으로 “편집 가능하면 관리자”라고 말할 수 없습니다.

| 개념 | 코드·설계에서의 연결 |
|---|---|
| 집합과 교집합 | 두 접근 조건을 동시에 만족하는 사용자 |
| 함수 | 입력마다 정해진 출력이 대응하는 규칙 |
| 관계 | 사용자와 문서의 소유·공유 관계 |
| 전칭·존재 | 모든 요청이 검증됨 / 허용 가능한 경로가 하나 존재 |

## 불변식과 귀납적 사고

반복문의 불변식은 반복 전후에 유지해야 할 성질입니다. 이미 처리한 원소의 합이 변수 total에 들어 있다는 성질을 정하면 초기값, 한 단계의 갱신, 종료 시 결과를 연결할 수 있습니다. 귀납법도 시작 조건과 다음 단계로의 보존을 보여 줍니다.

검증 예시는 작은 배열 [2, 3, 5]입니다. 처음 total=0이고, 원소를 하나씩 더한 뒤 total이 처리한 접두 구간의 합인지 확인합니다. 이 세 값에서 성공했다는 사실만으로 모든 배열을 증명한 것은 아닙니다.

## 반례와 경계 조건

“모든 경우”라는 주장은 반례 하나로 틀릴 수 있습니다. 빈 집합, 0, 음수, 중복, 최대 범위를 살피면 숨은 가정을 찾기 쉽습니다. 확률적인 관측과 논리적인 보장도 구분해야 합니다.
