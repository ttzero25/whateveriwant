# 비트·바이트와 데이터 표현

> **TL;DR**
>
> 컴퓨터는 비트 패턴을 규칙에 따라 숫자·문자·명령어로 해석합니다. 같은 바이트도 자료형과 인코딩이 다르면 다른 의미가 되며, 문자 수와 바이트 수는 같지 않을 수 있습니다.

AI 작성 해설

## 무엇을 표현하는가

| 용어 | 의미 | 예시 |
|---|---|---|
| Bit | 0 또는 1의 정보 단위 | `1` |
| Byte | 현대 시스템에서 보통 8비트 | `01000001` |
| Integer | 정해진 방식으로 해석한 정수 | 부호 없는 8비트: 0~255 |
| Encoding | 문자와 바이트를 연결하는 규칙 | UTF-8 |
| Floating point | 유효숫자와 지수로 근사한 수 | 이진 부동소수점 |

## 직접 계산하기

부호 없는 8비트는 `2^8 = 256`개 값을 구분하므로 범위는 0~255입니다. `01000001`을 정수로 읽으면 65이고, ASCII 문자로 읽으면 `A`입니다.

Python에서 `len('가')`는 1이지만 `len('가'.encode('utf-8'))`는 3입니다. 이 예시의 문자열 길이는 코드 포인트 기준이고, 사용자가 하나의 글자로 인식하는 단위와도 항상 일치하지 않습니다.

출처: [Python — Text and binary sequence types](https://docs.python.org/3/library/stdtypes.html#binary-sequence-types-bytes-bytearray-memoryview).

## 헷갈리기 쉬운 점

- 1 kB는 1,000바이트, 1 KiB는 1,024바이트입니다. 표기 관행은 제품마다 확인합니다.
- 텍스트를 바이트로 바꾸는 인코딩은 암호화가 아닙니다.
- 고정 폭 정수의 넘침 처리와 정수 크기는 언어·타입에 따라 다릅니다.
- 부동소수점의 근사 오차 때문에 계산 결과를 무조건 정확한 실수처럼 비교하면 안 됩니다.

## 다른 분야와 연결

파일 형식, 네트워크 직렬화, AI 입력 토큰화는 모두 데이터 표현 규칙에 의존합니다. 먼저 '이 값은 어떤 타입·단위·인코딩인가?'를 확인하세요.
