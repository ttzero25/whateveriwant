# 자료구조: 배열·스택·큐·해시·트리·그래프

> **TL;DR**
>
> 자료구조는 데이터를 배치하고 접근하는 방식입니다. 저장할 값의 종류뿐 아니라 자주 수행할 조회·삽입·삭제와 순서 조건을 기준으로 선택해야 합니다.

## 구조별 비교

| 구조 | 핵심 성질 | 사용 예 |
|---|---|---|
| 배열·동적 배열 | 인덱스로 접근 | 연속적인 측정값 |
| 연결 리스트 | 노드를 연결 | 노드 위치를 알 때 연결 변경 |
| 스택 | LIFO: 마지막 입력을 먼저 꺼냄 | 되돌리기, 호출 관리 |
| 큐 | FIFO: 먼저 입력한 값을 먼저 꺼냄 | 순서대로 작업 처리 |
| 해시 테이블 | 키로 위치를 계산 | ID로 객체 조회 |
| 트리 | 계층 관계 | 디렉터리, 검색 트리 |
| 그래프 | 노드 사이의 관계 | 경로, 의존성 |

## 스택과 큐를 직접 확인하기

`A → B → C` 순서로 넣었다면 스택은 `C`부터, 큐는 `A`부터 꺼냅니다. Python에서는 스택을 리스트의 `append/pop`으로 구현할 수 있습니다. 큐는 양 끝 연산에 맞춘 `collections.deque`를 사용할 수 있습니다.

출처: [Python — Data Structures](https://docs.python.org/3/tutorial/datastructures.html).

## 연산 비용을 함께 보기

동적 배열의 인덱스 조회는 통상 O(1)이지만 중간 삽입은 뒤쪽 원소 이동 때문에 O(n)입니다. 끝에 추가는 통상 분할상환 O(1)이며, 용량 확장 한 번은 O(n)이 될 수 있습니다.

해시 조회는 적절한 해시와 부하율 아래 평균적으로 O(1)이지만 최악도 항상 O(1)인 것은 아닙니다. 연결 리스트의 삽입도 삽입 위치를 찾는 비용을 포함하는지 구분해야 합니다. 트리는 균형 여부에 따라 탐색 비용이 달라집니다.
