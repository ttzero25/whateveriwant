# 선형 회귀: 숫자를 예측하는 기본 모델

> **TL;DR**
>
> 선형 회귀는 입력 특성의 가중합으로 연속 값을 예측합니다. 계수의 크기만으로 인과관계를 판단하지 말고, 새 데이터의 오차로 모델을 평가합니다.

AI 작성 해설 · 소유자 검토 전 · 출처 확인: 2026-09-10

## 언제 사용하는가

가격, 소요 시간, 수요처럼 숫자로 표현되는 목표를 예측할 때 출발점으로 사용할 수 있습니다. 결과 해석이 비교적 쉬워 더 복잡한 모델과 비교할 기준선으로도 유용합니다.

## 모델과 학습

$$\hat y=b+\sum_{j=1}^{d}w_jx_j$$

`x_j`는 입력 특성, `w_j`는 가중치, `b`는 편향입니다. 학습은 데이터에 맞는 가중치와 편향을 찾는 과정입니다. 대표적인 손실은 평균제곱오차입니다.

$$\mathrm{MSE}=\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat y_i)^2$$

출처: [Google — Linear regression](https://developers.google.com/machine-learning/crash-course/linear-regression).

## 직접 계산해 보기

가상 모델이 `소요 시간 = 3 × 거리 + 5`라면, 거리 4에서 예측은 17입니다. 실제 값이 20이면 잔차 `실제−예측`은 3, 제곱오차는 9입니다. 여러 샘플의 제곱오차를 평균하면 MSE가 됩니다. 이 계수는 설명을 위해 정한 값이며 실제 측정 결과가 아닙니다.

## 헷갈리기 쉬운 점

- '선형'은 모델 파라미터에 대한 선형성을 뜻합니다. 제곱한 입력 특성을 추가한 모델도 파라미터에는 선형일 수 있습니다.
- MSE는 큰 오차에 더 큰 페널티를 주므로 극단값에 민감합니다.
- 관측한 범위를 벗어난 외삽은 별도 검증이 필요합니다.
- 특성의 단위가 다르면 가중치 크기를 그대로 중요도처럼 비교하기 어렵습니다.

## 확인 질문

MSE가 낮아졌는데 특정 구간의 오차는 커졌다면 모델이 모든 사용자에게 개선됐다고 할 수 있을까요? 전체 지표와 구간별 오차를 함께 확인하세요.
