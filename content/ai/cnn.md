# CNN: 지역 패턴을 학습하는 합성곱 신경망

> **TL;DR**
>
> CNN은 작은 필터를 여러 위치에 공유해 이미지 같은 데이터의 지역 패턴을 학습합니다. 공간 크기와 채널 수를 구분하고, 커널·스트라이드·패딩이 출력 모양에 미치는 영향을 확인해야 합니다.

AI 작성 해설

## 핵심 구성

| 요소 | 역할 |
|---|---|
| Kernel / 필터 | 주변 입력과 곱해 더하는 학습 가중치 |
| Feature map | 필터를 여러 위치에 적용한 출력 |
| Stride | 필터가 이동하는 간격 |
| Padding | 경계 처리와 출력 크기 조절 |
| Pooling | 지역 출력을 요약해 공간 해상도를 줄이는 연산 |

합성곱층 뒤에 활성화 함수를 적용하고, 이를 쌓아 더 넓은 범위의 표현을 만들 수 있습니다. Pooling은 가능한 구성 요소이며 모든 CNN에서 필수는 아닙니다.

출처: [TensorFlow — Convolutional Neural Network](https://www.tensorflow.org/tutorials/images/cnn).

## 출력 모양 계산

Dilation이 1일 때 한 축의 출력 크기는 다음과 같습니다.

$$O=\left\lfloor\frac{N+2P-K}{S}\right\rfloor+1$$

입력 크기 `N=8`, 커널 `K=3`, 패딩 `P=0`, 스트라이드 `S=1`이면 출력은 6입니다. 이 식은 대칭 패딩을 가정합니다.

가상의 RGB 이미지가 `32×32×3`이고 `3×3` 필터 16개를 valid padding과 stride 1로 적용하면 출력은 `30×30×16`입니다. 각 필터는 입력 채널 전체를 함께 처리합니다. Batch 축의 위치는 프레임워크 설정에 따라 달라집니다.

## 헷갈리기 쉬운 점

필터는 보통 데이터로 학습하며 '이 필터는 항상 눈을 찾는다'고 미리 정해두는 것은 아닙니다. 가중치 공유는 파라미터 수를 줄이지만 이동·회전 등에 대한 완전한 불변성을 자동으로 보장하지 않습니다.
