# LLM의 생성과 추론

> **TL;DR**
>
> 자기회귀 언어 모델은 앞선 토큰들을 조건으로 다음 토큰의 분포를 계산하고 반복해 텍스트를 생성합니다.
> 다음 토큰 선택을 반복해 생성하며, 유창한 문장도 사실 확인이 필요합니다.

AI 작성 해설 · 소유자 검토 전 · 출처 확인: 2026-09-10

## 생성 과정

`입력 구성 → 토큰화 → 다음 토큰 점수 계산 → 토큰 선택 → 반복 → 종료`

대화형 모델에는 역할과 메시지 경계를 표현하는 chat template이 사용될 수 있습니다. 모델이 기대하는 입력 형식을 맞춰야 합니다. 종료 토큰이나 생성 길이 제한에 도달하면 멈춥니다.

| 용어 | 의미 |
|---|---|
| Logits | 확률 변환 전 토큰별 점수 |
| Greedy decoding | 매번 가장 높은 점수의 토큰 선택 |
| Sampling | 분포에서 토큰 추출 |
| Temperature | 샘플링 분포의 날카로움 조절 |
| Context window | 처리 가능한 문맥의 토큰 범위 |

샘플링 온도를 낮추면 일반적으로 높은 점수의 토큰에 집중합니다. 지원 값과 길이 제한의 의미는 모델·API마다 확인해야 합니다.

출처: [Hugging Face — Text generation](https://huggingface.co/docs/transformers/llm_tutorial).

## 헷갈리는 점

Inference는 학습한 모델을 실행한다는 뜻이며 논리적 도출을 뜻하는 reasoning과 같지 않습니다. 일반적인 생성 요청은 가중치를 바꾸지 않습니다.

유창한 답변은 사실성의 보장이 아닙니다. 이 백과의 적용 원칙으로 날짜·수치·인용을 원문과 대조하고 근거가 실제 주장을 뒷받침하는지 확인합니다.
