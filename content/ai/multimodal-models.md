# 멀티모달 모델: 텍스트·이미지·오디오를 함께

> **TL;DR**
>
> 멀티모달 모델은 서로 다른 종류의 데이터(텍스트·이미지·오디오)를 하나의 표현 공간으로 연결해 다룹니다. 각 모달리티를 임베딩으로 바꾸고, 정렬·융합해 교차 검색·설명·생성 같은 과제를 수행합니다.

AI 작성 해설 · 소유자 검토 전 · 출처 확인: 2026-09-10

## 왜 멀티모달인가

현실 데이터는 한 종류가 아닙니다. 이미지에 설명을 붙이고, 음성을 글로 옮기고, 문서 속 그림을 이해하려면 여러 모달리티를 함께 다뤄야 합니다. 핵심은 서로 다른 입력을 **비교 가능한 표현**으로 바꾸는 것입니다. 임베딩 개념은 [토큰과 임베딩](tokens-and-embeddings.md)과 이어집니다.

## 공통 표현 공간

각 모달리티에 전용 인코더를 둡니다. 텍스트는 [Transformer](transformer.md), 이미지는 [CNN](cnn.md)이나 비전 트랜스포머로 벡터를 만듭니다. 이 벡터들을 **같은 공간**에 놓으면, 이미지와 그 설명이 가까이 위치하도록 학습할 수 있습니다. 대표적 방법이 대조 학습(contrastive learning)으로, 짝이 맞는 쌍은 끌어당기고 아닌 쌍은 밀어냅니다.

```python
import numpy as np

def cosine(a, b):
    return a @ b / (np.linalg.norm(a) * np.linalg.norm(b))

# CLIP류: 이미지·텍스트 인코더가 같은 공간의 벡터를 낸다
img_vec = image_encoder(image)          # (d,)
texts = ["강아지 사진", "자동차 사진", "해변 풍경"]
txt_vecs = [text_encoder(t) for t in texts]

# 이미지에 가장 잘 맞는 캡션을 코사인 유사도로 검색 (제로샷 분류)
best = max(range(len(texts)), key=lambda i: cosine(img_vec, txt_vecs[i]))
print("예측:", texts[best])
```

이렇게 정렬된 공간이 있으면 학습하지 않은 라벨도 텍스트로 표현해 분류할 수 있습니다(제로샷).

## 융합 전략

- **초기 융합**: 원시 특징 단계에서 합침(모달리티 간 상호작용을 깊게, 정렬 필요).
- **후기 융합**: 각 모달리티를 따로 처리한 뒤 결과를 결합(단순·견고).
- **교차 어텐션**: 한 모달리티가 다른 모달리티에 주의를 기울여 상호 참조(현대 비전-언어 모델의 방식).

## 과제 예시

| 과제 | 입력 → 출력 |
|---|---|
| 캡셔닝 | 이미지 → 설명 텍스트 |
| 시각 질의응답(VQA) | 이미지 + 질문 → 답 |
| 교차 검색 | 텍스트 → 관련 이미지(또는 반대) |
| 텍스트→이미지 생성 | 프롬프트 → 이미지([생성 모델](generative-models.md)) |

## 한계와 유의점

- **정렬 데이터 의존**: 짝지어진 대량 데이터가 필요하고, 그 편향이 그대로 학습됩니다.
- **모달리티 불균형**: 한 모달리티가 지배해 다른 것을 무시할 수 있습니다.
- **환각·근거**: 이미지에 없는 것을 설명으로 지어낼 수 있어 평가가 중요합니다. [분류 모델 평가](evaluation.md)
- **보안**: 이미지·오디오에 숨긴 지시가 모델 입력이 되면 [LLM 프롬프트 인젝션 방어](../ai-for-security/llm-prompt-injection.md)의 간접 주입 표면이 됩니다.
