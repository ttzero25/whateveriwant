# 역전파와 자동 미분: 손실에서 기울기까지

> **TL;DR**
>
> 역전파는 계산 그래프에서 연쇄 법칙으로 손실의 기울기를 구합니다. 자동 미분이 기울기를 계산하고 옵티마이저가 그 기울기를 이용해 파라미터를 갱신합니다.

AI 작성 해설

## 순전파와 역전파

순전파는 입력에서 예측과 손실을 계산합니다. 역전파는 손실이 각 중간값과 파라미터에 얼마나 민감한지 계산합니다. 복잡한 함수를 기본 연산으로 나눠 각 연산의 미분을 연결하므로 유한 차분으로 매번 조금씩 흔들어 보는 방식과 다릅니다.

## 작은 수치 예시

예측 ŷ=w·x, 손실 L=(ŷ−y)²를 가정합니다. x=2, y=6, w=1이면 ŷ=2이고 L=16입니다. dL/dw=2(w·x−y)x이므로 기울기는 −16입니다. 학습률 0.1로 w를 갱신하면 w=2.6, 새 손실은 0.64입니다. 이 간단한 예에서 감소했지만 모든 학습률과 모델에서 감소가 보장되는 것은 아닙니다.

| 단계 | 하는 일 |
|---|---|
| Forward | 예측·손실 계산과 필요한 연산 기록 |
| Backward | 파라미터에 대한 기울기 계산 |
| Optimizer step | 기울기와 최적화 상태로 파라미터 갱신 |
| Gradient reset | 의도하지 않은 누적 방지 |

## 그래프와 기울기 관리

일부 프레임워크는 backward 호출마다 기울기를 누적합니다. 여러 미니배치를 의도적으로 누적할 때와 매 단계 새 기울기를 쓸 때를 구별해야 합니다. 그래프를 끊는 연산이나 기울기 기록을 비활성화한 구간은 학습 흐름에 영향을 줍니다. [PyTorch: Automatic Differentiation](https://docs.pytorch.org/tutorials/beginner/basics/autogradqs_tutorial.html)
