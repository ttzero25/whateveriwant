# 앙상블: 배깅·랜덤 포레스트·부스팅

> **TL;DR**
>
> 앙상블은 여러 모델을 결합해 예측을 개선하는 접근입니다. 모델들의 오류가 얼마나 겹치는지와 결합 방식이 중요하며 모델 수만 늘린다고 항상 좋아지지 않습니다.

AI 작성 해설 · 소유자 검토 전 · 출처 확인: 2026-09-10

## 서로 다른 오류를 결합하기

같은 데이터와 같은 방식으로 만든 동일한 모델의 평균은 새로운 정보를 거의 더하지 못합니다. 앙상블은 표본·특징·학습 방식의 차이로 생기는 다양한 예측을 활용합니다.

| 방식 | 학습과 결합 | 특징 |
|---|---|---|
| Bagging | 재표집한 데이터로 여러 모델을 학습해 평균·투표 | 불안정한 모델의 분산을 줄이는 데 도움 |
| Random forest | 표본과 분할 후보 특징의 무작위성을 이용한 트리 집합 | 트리 사이의 유사한 오류를 줄이려 함 |
| Boosting | 앞선 모델의 부족함을 보완하도록 순차 학습 | 학습률·깊이·반복 수의 영향 |
| Stacking | 여러 모델의 예측을 다른 모델의 입력으로 결합 | 메타 모델 학습에서 누출 방지 필요 |

[scikit-learn: Ensembles](https://scikit-learn.org/stable/modules/ensemble.html)

## 비용과 해석

큰 앙상블은 메모리와 추론 시간을 더 사용할 수 있습니다. 운영에서는 성능뿐 아니라 지연·업데이트·설명 요구를 함께 평가합니다. 특징 중요도가 높다는 사실은 그 특징이 결과를 인과적으로 일으켰다는 뜻이 아닙니다.

## 예시: 메일 분류

단일 트리와 랜덤 포레스트를 같은 시간 분할 데이터에서 비교합니다. 탐지 재현율이 개선되었어도 경보량이 검토 예산을 넘으면 임계값과 비용을 다시 평가해야 합니다. 부스팅을 추가할 때도 시험 데이터를 반복적으로 선택에 사용하지 않습니다.
