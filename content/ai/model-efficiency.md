# 모델 효율화: 양자화·프루닝·증류

> **TL;DR**
>
> 큰 모델을 그대로 배포하면 지연·메모리·비용이 큽니다. 양자화(정밀도 낮추기), 프루닝(불필요한 가중치 제거), 지식 증류(작은 모델에 지식 이전)로 정확도 손실을 최소화하며 모델을 가볍게 만듭니다.

AI 작성 해설

## 왜 필요한가

학습된 신경망([신경망과 텐서](neural-networks.md))은 크고 무거워, 모바일·엣지·대규모 서빙에서 지연과 비용이 문제입니다. 효율화는 "같은 일을 더 적은 자원으로" 하게 만듭니다. 추론 관점은 [LLM의 생성과 추론](llm-inference.md)과 이어집니다.

| 기법 | 아이디어 | 주로 줄이는 것 |
|---|---|---|
| 양자화 | 가중치·활성값 정밀도 낮춤(FP32→INT8/4) | 메모리·지연 |
| 프루닝 | 영향 적은 가중치·뉴런 제거 | 연산·크기 |
| 지식 증류 | 큰 교사 모델의 출력을 작은 학생 모델이 모방 | 모델 크기 |

## 양자화: 정밀도를 낮춘다

32비트 실수를 8비트 정수로 표현하면 메모리가 1/4로 줄고 정수 연산이 빨라집니다. 실수 범위를 정수 격자에 대응시키는 스케일·영점을 씁니다. 부동소수점 표현은 [부동소수점과 수치 오차](../cs/floating-point.md)와 이어집니다.

```python
import numpy as np

def quantize_int8(w):
    scale = np.abs(w).max() / 127          # 실수 범위를 [-127,127]로 매핑
    q = np.round(w / scale).astype(np.int8)  # 정수로 저장(메모리 1/4)
    return q, scale

def dequantize(q, scale):
    return q.astype(np.float32) * scale     # 사용 시 근사 복원

w = np.array([0.12, -0.98, 0.44, -0.05], dtype=np.float32)
q, s = quantize_int8(w)
# dequantize(q, s) ≈ w (약간의 오차 = 양자화 손실)
```

정밀도를 낮추면 약간의 정확도 손실이 따르므로, 학습 후 양자화(PTQ)와 양자화를 고려해 학습하는 방식(QAT)을 상황에 맞게 씁니다.

## 프루닝과 증류

- **프루닝**: 크기가 작은 가중치나 기여가 낮은 뉴런·헤드를 제거합니다. 비정형 프루닝은 크기를 줄이고, 정형(구조적) 프루닝은 실제 속도까지 높입니다. 정규화·희소성과 연결됩니다([정규화](regularization.md)).
- **지식 증류**: 크고 정확한 교사 모델의 부드러운 출력(확률 분포)을 작은 학생 모델이 모방하도록 학습해, 작은 모델의 성능을 끌어올립니다.

## 트레이드오프

효율화는 대개 **정확도 ↔ 크기·속도**의 절충입니다. 목표 지연·메모리 예산을 정하고, 압축 후 정확도를 검증([분류 모델 평가](evaluation.md))합니다. 여러 기법을 조합하기도 합니다(증류 후 양자화 등).
