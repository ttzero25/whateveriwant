# 데이터 분할과 일반화

> **TL;DR**
>
> 일반화는 학습에 사용하지 않은 데이터에서도 유용한 예측을 하는 능력입니다.
> 학습·검증·테스트를 분리하고, 중복과 미래 정보가 평가에 섞이지 않도록 확인합니다.

AI 작성 해설

## 핵심 원리

| 데이터 | 역할 |
|---|---|
| Training set / 학습 세트 | 파라미터 조정 |
| Validation set / 검증 세트 | 설정·모델·임계값 선택 |
| Test set / 테스트 세트 | 선택을 끝낸 모델의 최종 평가 |

과적합(overfitting)은 학습 데이터에는 잘 맞지만 새로운 데이터에는 성능이 떨어지는 현상입니다. 학습 손실이 줄어드는데 검증 손실이 증가하면 의심할 수 있습니다. 과소적합(underfitting)은 학습 데이터의 패턴도 충분히 표현하지 못하는 상태입니다.

출처: [Google — Overfitting](https://developers.google.com/machine-learning/crash-course/overfitting/overfitting).

## 적용 예시

아래는 백과에서 구성한 사례입니다. 시간순 이벤트를 예측한다면 과거로 학습하고 이후 기간으로 평가하는 구성이 실제 사용 환경에 가깝습니다. 같은 문서의 복제본이 학습·테스트 양쪽에 있으면 성능이 부풀 수 있습니다.

전처리의 평균·표준편차도 학습 세트에서 구해 나머지 세트에 적용합니다. 테스트 결과를 반복해서 보며 설정을 바꾸면 테스트 세트가 사실상 모델 선택에 쓰입니다. 평가에만 있어야 할 정보가 학습이나 선택에 들어가는 데이터 누출(data leakage)에 주의해야 합니다.

## 헷갈리는 점

성능 저하는 과적합 외에도 운영 데이터의 분포 변화, 레이블 오류, 전처리 차이에서 발생합니다. 데이터의 시점·중복·그룹을 먼저 확인하세요.
