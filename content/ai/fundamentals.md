# AI·ML·딥러닝과 학습 방식

> **TL;DR**
>
> AI는 지능적 작업을 수행하는 시스템을 다루며, 머신러닝은 데이터에서 패턴을 학습하는 접근이고, 딥러닝은 여러 층의 신경망을 사용하는 머신러닝입니다.
> AI·ML·딥러닝은 범위가 다르며, 학습 방식은 어떤 신호로 배우는지에 따라 구분합니다.

AI 작성 해설

## 핵심 구분

AI에는 사람이 규칙을 작성하는 방식도 포함됩니다. 머신러닝(ML)은 데이터와 학습 목표로 모델의 파라미터를 조정합니다. 딥러닝(DL)은 유용한 표현을 여러 층에 걸쳐 학습합니다. LLM은 언어를 다루는 대규모 모델이며 AI 전체를 뜻하지 않습니다.

| 학습 방식 | 학습 신호 | 예시 |
|---|---|---|
| 지도학습 | 입력과 목표 정답 | 스팸 여부 분류 |
| 비지도학습 | 정답 없이 데이터 구조 | 비슷한 문서 묶기 |
| 자기지도학습 | 데이터 자체에서 만든 목표 | 다음 토큰 예측 |
| 강화학습 | 행동에 따른 보상 | 시뮬레이션의 제어 정책 학습 |

분류는 범주를, 회귀는 연속 값을 예측합니다. 생성 모델은 학습한 분포를 바탕으로 텍스트나 이미지 같은 출력을 만듭니다.

## 예시와 오해

면적으로 주택 가격을 예측하면 회귀, 가격을 '저가/고가'로 나눠 예측하면 분류입니다. 같은 데이터도 목표에 따라 문제가 달라집니다.

모든 AI가 생성형 AI는 아닙니다. 모델이 크다는 이유만으로 주어진 문제에 더 적합하다고 결론 내릴 수도 없습니다.
